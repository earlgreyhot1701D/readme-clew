# Le Petit Mot

A mobile-first 30-day French learning app.

## Stack
- Vanilla HTML, CSS, JavaScript (no framework)
- Web Speech API (fr-FR)
- localStorage for progress
- Vercel hosting

Zero runtime AI calls. All 30 days static in `curriculum.js`.

## Run
Open `index.html` in browser. No build step.

Live at https://lepetitmot.vercel.app
