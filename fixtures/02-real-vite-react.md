# my-portfolio

Personal portfolio built with Vite and React.

## Tech stack
- Vite 5
- React 18
- TypeScript
- Tailwind CSS

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and set `VITE_ANALYTICS_ID`
3. `npm run dev` for local
4. `npm run build` for production

See `docs/deploy.md` for deployment.
